# 重新定义价值 · Mac 桌面便签 0.10.25

紫黑科技风桌面工作台，macOS 13+，发布包支持 Apple Silicon / Intel Universal。顶部保留整月飞书日历，下方分页依次为“一览、待办、项目、商务、开发、复盘、财务、备忘”，方向键切换也遵循同一顺序。“一览”汇总待办、项目、商务、开发、复盘和备忘，按日期统一混排：今天 → 明天 → 后续日期，同日按填写的时间先后排列。

## 使用

打开「重新定义价值.app」，默认出现在屏幕可用区域右上角，保留上次窗口大小，并在底部 Dock 显示 App 图标；点击 Dock 图标可唤回窗口。拖动顶部空白处摆放，点击锁图标锁住位置。设置可选择「锁定后贴在桌面」「普通浮窗」「始终置顶」。桌面模式解锁时可摆放，锁定后位于普通窗口后面；仍可点击、勾选和输入。顶部减号、菜单栏“最小化”及 Command-M 均使用原生最小化，Dock 图标保留；点击 Dock 图标恢复窗口。关闭窗口也继续在后台运行并保留 Dock 图标；选择“退出重新定义价值”或 Command-Q 后先保存再退出，Dock 图标随之消失。菜单栏图标也可以重新显示、调整位置或退出。

月历支持左右箭头、横向拖动和触控板横向滚动。点击日期自动展开当天的“日程明细”，汇总飞书日程、本机待办、商务和开发安排；下方各个分页不会按该日期筛选，也不会因此跳回列表顶部。「今天」返回当天月历。

“日程明细”下面是“时间管理”。点击标题可整体收起或展开分页、记录和导出按钮；记住上次展开状态，收起不会清空内容，已解锁财务同时重新锁定。时间管理收起时，已展开的日程明细填满剩余窗口高度，可独立上下滚动；重新展开时间管理后，日程恢复紧凑高度。标题右侧保留保存状态。

## 记录编辑与显示方式

待办、项目与商务记录可在“一览”和各自分页单击名称、时间或进度备注打开编辑，保存后更新原记录。其他本机已写过的开发、复盘、备忘和已解锁财务可双击打开编辑。单击完成框仍用于勾选；键盘聚焦记录后按 Enter / F2 也可编辑。复盘点击“新增”写一条新的，双击旧条只修改该条。飞书日程保持只读，在飞书中维护。

项目、开发支持“短列表 / 长列表”：短列表显示紧凑摘要，长列表展开完整说明。待办页和商务页也始终以单行展示名称：待办右侧小字显示时间，商务右侧显示备注，长短列表只调整行距。“一览”始终以单行展示每条记录：左侧名称及类型标签，待办右侧显示时间，项目和商务右侧显示备注；过长备注以省略号显示，编辑窗口保留完整内容与换行。使用期间可以切换；每次重新打开应用，默认进入“一览 · 长列表”。

“一览”将各类记录合并为同一条时间线，左边显示日期小标，未完成工作从今天开始按日期由近到远排列；同一天先按待办时间或开发开始时间排序，无时间的记录排在当天后面，同一时间再按待办、项目、商务、开发、复盘、备忘区分。过往未完成工作归到今天继续显示，保留原始日期；历史复盘和备忘可在“过往记录”中展开查看。已完成的待办、项目、商务、开发统一在最后的“已完成”区域直接显示，按日期从新到旧排列，包含当天刚完成的记录。工作项保留类型小标签，复盘和备忘显示正文摘要；点击可编辑原记录，右上角可选择六种类型新增。财务保留独立入口。

## 累计时间流

待办、项目、商务、开发及一览统一将未完成记录放在前面，已完成记录放在末尾，不受完成记录原日期影响；勾选或修改状态后立即重排，取消勾选返回未完成区域。已完成记录直接展开，按日期从新到旧显示，归档视图也遵循这个规则。未完成的一览和待办从今天开始往后排列，其他分页未完成区域按记录日期从新到旧排列。左边显示月/日和年份（当天显示“今天”）。一览和待办同日按填写时间先后排列，未填时间排在当天后面；其他分页同日较新记录优先显示；上下滚动可查看历史。新增记录默认今天，待办、项目、商务、开发、财务可在表单中修改日期。旧项目优先沿用已有日期或时间戳，无法确定时标记“未标日期”。

| 分页 | 使用规则 |
| --- | --- |
| 待办 | 点击标题右侧“＋新增待办”打开表单，填写事项、日期和可选时间；底部输入框仍可快速添加今天的事项。可修改或清空时间；右侧小字显示时间。未完成记录从今天开始按日期、时间排序，过往未完成继续显示在今天，原始日期保留。今日及历史已完成记录统一在末尾直接显示，取消勾选可恢复。 |
| 项目 | 填写名称、日期和进度备注；一览与项目列表直接展示备注，长列表保留完整换行，短列表显示紧凑摘要。完成仍用左侧勾选，旧的下一步行动与完成状态保留；支持归档/恢复。 |
| 商务 | 记录客户、事项、推进状态、日期与进度备注。单击名称或备注继续编辑；列表保持名称和右侧小字备注同一行，编辑窗口保留完整备注与换行。支持完成、归档/恢复。 |
| 开发 | 记录项目、事项、日期、时间段、状态与开发目标。所有日期累计保留；支持完成、编辑、归档/恢复。 |
| 复盘 | 每次点“新增”打开空白记录，同一天可新增多条。输入自动保存为该条草稿，点“提交复盘”后返回列表并显示已提交时间。双击旧条修改，只更新该条；修改后可再次提交，不影响同日其他记录。“补写”可选过去日期，每次也新建一条；“搜索”按日期或正文查找每条记录。空白不新建、不提交，保存失败保留草稿。换日不改变正在写的记录日期，新点“新增”才默认使用新一天。旧版按日复盘原样保留，其原日期保持固定，正文仍可修改。 |
| 财务 | 记录收入/支出、金额、日期、往来方、财务阶段和备注。金额按人民币“分”保存，最多两位小数；支持双击编辑、归档/恢复。新增默认收入，阶段可选择待接洽、待交付、待结算、已结算（实际营收）；支出保留待付款/已结清。仅为本机账目记录，不进行转账或付款。 |
| 备忘 | 最后一个分页，记录灵感、资料和临时想法。点击“新增”，选择日期并填写内容，输入后自动保存，回车可换行，点击“完成”关闭编辑；双击旧备忘继续修改。按日期累计，最新在上，支持上下滚动、归档/恢复，并包含在导出中；不随月历选日或换日清空。 |

解锁后，财务标题右侧显示“待接洽 / 待交付 / 待结算 / 预估营收 / 实际营收”五项金额汇总（元）。预估营收 = 待接洽 + 待交付 + 待结算 + 已结算；实际营收只累计已结算收入。五项均排除支出、归档和已删除账目。推进阶段及结算不会重复增加预估营收。修改金额、切换阶段或归档后立即重算；切换月份不改变汇总范围。新增和双击编辑账目时使用同一组阶段选项。旧版“接洽 / 待收 / 实收”分别显示为“待接洽 / 待结算 / 已结算”，保留原状态值和金额，不自动改变账目的实际阶段；可双击自行调整。

标签支持点击和方向键、Home、End。每次启动默认显示“一览 · 长列表”，按日期和时间汇总待办、项目、商务、开发、复盘和备忘。每个列表独立滚动；已完成事项与历史内容不会因为切换月历日期消失。归档记录通过各分页的“归档”入口查看并恢复。

复盘分页中的每条正文完整展开，保留段落和换行，不再截为三行。长文和多条记录可在复盘列表中上下滑动，右侧滚动条提示当前位置；双击记录可继续修改。

月历日期格直接显示“时间＋事项”，飞书为蓝色，本机为红色；同一来源优先显示时间较早的有时刻安排，其余保留“＋数量”。全天显示“全天”，跨天延续显示“跨天”，没填时间的事项只显示名称；悬停日期格可看全部事项和完整起止时间。复盘标记继续保留。“日程明细”可展开、收起；点击任意月历日期自动展开，仅显示该天飞书日程及本机待办、商务和开发安排。全天在前，其余按时间递增，未填时间的排在最后。跨天安排在覆盖的日期显示，原始起止时间不变，结束日期的零点不多算一天。已完成的本机记录仍可查看并标记“已完成”，归档和财务不进入日程明细。点击飞书条目查看只读详情，点击本机条目打开对应编辑器；保存、完成或删除后立即刷新。日期切换回到明细顶部，同日同步保留滚动位置，日历筛选只影响飞书来源。下方时间管理仍展示累计记录。

## 飞书 CLI 接入

飞书同步需要自行安装官方 `@larksuite/cli`。应用自动寻找 `~/.npm-global/bin/lark-cli`、`~/.local/bin/lark-cli`、Homebrew 与 PATH 中的 CLI，复用官方 CLI 的配置和凭据。界面本身不需要 Node；CLI 由本机 Node 运行。

1. 未安装时按[官方说明](https://github.com/larksuite/cli/blob/main/README.zh.md)执行 `npx @larksuite/cli@latest install`，完成本机应用配置。已有配置直接复用。
2. 在「设置 → 连接飞书 CLI」打开本人授权页面，仅申请 `calendar:calendar:readonly offline_access`。
3. 用户在飞书确认后，应用完成登录并读取日历，每分钟自动刷新，也可手动同步。
4. 在终端完成 CLI 登录后，启动应用会自动识别；未连接时，运行中的应用也会每分钟重新检测，或点击连接立即检查。

应用仅调用 `calendar calendars list` 与 `calendar events instance_view`，明确指定 `--as user`；不会把机器人空日历当作个人日程。Token 由官方 CLI 管理，不复制到网页或日志。断开仅停止本应用使用 CLI 并清空日历缓存，不注销其他工具共用的 CLI 登录。

### 可选手动 API 模式

在设置中展开「使用自建应用手动连接」：

1. 在[飞书开放平台](https://open.feishu.cn/app)创建企业自建应用，开通用户身份的 `calendar:calendar:readonly` 与 `offline_access`。
2. 添加重定向 URL：`http://127.0.0.1:41863/callback`。
3. 发布应用，将本人加入可用范围，按企业要求完成审批。
4. 把 App ID、App Secret 直接填进本机应用，然后授权。请不要把 Secret 发到聊天。

此模式的凭据存入 macOS 钥匙串。OAuth 使用 state、S256 PKCE 与飞书 v3 Token 端点，并保存轮换后的 Refresh Token。包内不预置凭据。

### 同步边界

- 应用运行时刷新当前月、下个月和查看中的月份；点选日期后会显示该天已同步的日程，列表右侧保留滚动条，可用滚轮、触控板或拖动滚动条上下查看。
- 全部读取成功后替换该月快照，使新增、修改、删除和取消跟随飞书；失败保留上次数据并显示错误。
- 日历列表完整分页；日程实例视图展开重复日程与例外，超过接口实例上限时递归拆分范围、按实例 ID 去重。
- 支持有 reader / writer / owner 权限的主日历、共享日历；不展示外接 Google、Exchange、资源或仅忙闲可见日历。
- 保留标题、时间、全天/多日、地点、备注、原始颜色数据和日程/会议链接，按本机时区显示；界面中飞书安排统一蓝色，本机添加的安排统一红色。
- 本机待办、项目、商务、开发与复盘不写回飞书；商务和开发是手动记录，不自动给飞书日程分类。
- 电脑睡眠、应用退出时不读取新变更；这不是飞书界面的即时镜像。

财务账目不再显示勾选框。待结算收入点击右侧“→ 已结算”完成结算，实际营收同步更新，预估营收保持不变；需要退回阶段时，打开账目编辑窗口选择“待结算”并保存。未结清账目按阶段分组，已结算收入和已结清支出统一放在列表最后；每组内部仍按日期从新到旧显示。推进或编辑阶段后立即调整位置，金额、原日期和备注均保留。

点击上方“待接洽、待交付、待结算”金额区域查看对应阶段收入；点击“预估营收”查看所有阶段收入，点击“实际营收”只看已结算收入。所选阶段会高亮，明细与该金额使用相同口径，排除归档、已删除账目和支出。“全部”返回未归档、未删除的全部收入及支出；“归档”单独查看归档记录。推进、修改阶段或删除后，明细和金额立即更新。

“全部”或“预估营收”明细中同时存在多个未结清阶段时，按待接洽、待交付、待结算、待付款分组，阶段之间用细线隔开，每组内部仍按日期从新到旧显示。已结算和已结清记录继续统一放在最后。单阶段筛选、归档和最近删除沿用原有日期顺序。

活动收入右侧有“→ 待交付”“→ 待结算”或“→ 已结算”按钮，点击一次推进一步：待接洽 → 待交付 → 待结算 → 已结算。保存成功后金额和明细同步更新；若正在查看原阶段，该账目会移出，可点击下一阶段查看。支出、已结算、归档及已删除账目没有推进按钮。需要调整或退回阶段时，在编辑窗口选择对应阶段并保存；点击账目名称或双击记录可编辑。

打开已有账目，在编辑窗口点击“删除账目”，保存成功后移入“最近删除”，不再计入普通账目和金额汇总。在“最近删除”打开账目，点击“恢复账目”可还原，保留原日期、金额、阶段、备注和归档状态；原为归档的账目恢复到归档中。最近删除不自动清空，继续加密保存并要求财务密码。完整导出也包含这些记录，阅读文档标注删除状态。

## 财务密码

首次进入财务页，点击“设置财务密码”，在本机安全输入框中输入两次密码（至少 6 位）；不要把密码发到聊天。已有账目会保留。设置完成后，后续打开应用需输入密码才能查看账目、金额汇总和数量。可在“设置 → 财务密码”验证旧密码后修改新密码。

切换离开财务分页、点击“锁定”、收起窗口、电脑休眠/锁屏，以及 5 分钟无操作后会重新锁定。锁定会清空网页中的账目与输入框，并阻止原生端读取或修改财务；“一览”不包含财务。点击“导出全部”时，锁定的财务会先要求密码验证；取消验证会取消整次导出。导出临时解锁的财务在结束后重新锁定。尚未设密且没有财务记录时可直接导出。

升级时先将旧财务加密并执行解密回读一致性校验，成功后才从普通 `state.json` 移除明文。首次设密前，迁移密钥暂存在本机钥匙串；界面仍保持锁定。设密后使用 PBKDF2-HMAC-SHA256（310,000 次、独立随机盐）派生 AES-256-GCM 密钥，并移除临时钥匙串密钥。密码只经过原生安全输入框，不写入网页、记录文件或日志。密码遗忘后无法解锁这份加密保险箱，请妥善保管。

该密码保护 Mac 应用和新版财务文件。旧版导出的 JSON、历史截图与既有备份不会随新密码自动加密。浏览器仅预览工作列表，财务设密与解锁需要 Mac 应用。

## 自动保存与复盘归档

输入后 220ms 自动保存，失去焦点、切换日期、退出时也会保存。为兼容旧版，目录沿用 `~/Library/Application Support/在场/`，应用标识保持 `local.zaichang.desktop`。

- `state.json`：非财务记录及设置。旧复盘原文继续保存在 `thoughts`，旧提交时间在 `reviewSubmitted`；新增复盘逐条保存在 `reviews` 数组，包含独立标识、日期、正文、创建/修改时间和提交时间。同日多条互不覆盖，不再保存明文财务。
- `finance-vault.json`：加密财务保险箱。
- `calendar-cache.json`：飞书日历快照。
- `reflections/YYYY-MM-DD.md`：旧版按日复盘的 Markdown，继续保留；修改原文时更新该文件。
- `reflections/entries/记录标识.md`：每条新增复盘的独立 Markdown，正文标题包含记录日期；编辑只更新本条文件。新版启动时补齐新旧复盘归档。
- 目录权限 0700，文件权限 0600。手动 API 模式的凭据保存在钥匙串服务 `local.zaichang.desktop`。

「每日复盘 → 历史」可搜索日期、正文并回看；归档文件夹可在历史弹窗中打开。

点击底部“导出全部”，选择保存位置，即可生成一个 ZIP：包含待办、项目、商务、开发、所有日期的复盘、财务、备忘、归档记录、设置，以及本机已同步的全部飞书日程，不受当前分页、选中日期或日历隐藏筛选影响。压缩包内有 `全部内容.md`（可阅读文档）、`完整备份.json`（完整数据）和 `导出说明.txt`。飞书密码、Token、财务密码和加密密钥均不导出；已解锁的财务记录会以明文包含在文件中，请自行保管。取消密码验证或保存窗口会取消导出；保存失败不会提示成功。日程只包含本机已经同步的范围；导出文件暂不提供应用内自动恢复。浏览器预览仅下载明确标记范围的 JSON，完整 ZIP 和财务验证需要 Mac 应用。跨设备备份可把导出文件存到自己选择的位置。

## 提醒

设置可开启每日复盘系统通知并选择时间。飞书日程提醒提前 10 分钟，针对已同步的未来非全天日程，每次最多安排 50 条。系统通知、专注模式、休眠会影响送达。开发日程的本机时间段用于记录，不单独创建系统通知。首次开启提醒才请求系统通知权限。
