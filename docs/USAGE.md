# 重新定义价值 · Mac 桌面便签 0.10.4

紫黑科技风桌面工作台，macOS 13+，发布包支持 Apple Silicon / Intel Universal。顶部保留整月飞书日历，下方分页依次为“一览、待办、项目、商务、开发、复盘、财务、备忘”，方向键切换也遵循同一顺序。“一览”依次汇总待办、项目、商务、开发、复盘和备忘，同类记录按日期从新到旧排列。

## 使用

打开「重新定义价值.app」。拖动顶部空白处摆放，点击锁图标锁住位置。设置可选择「锁定后贴在桌面」「普通浮窗」「始终置顶」。桌面模式解锁时可摆放，锁定后位于普通窗口后面；仍可点击、勾选和输入。减号收起，菜单栏图标可以显示、调整位置或退出。

月历支持左右箭头、横向拖动和触控板横向滚动。点击日期可查看月历标记，飞书时间线始终从今天开始；下方各个分页不会按该日期筛选，也不会因此跳回列表顶部。「今天」返回当天月历。

“飞书日程”下面是“时间管理”。点击标题可整体收起或展开分页、记录和导出按钮；记住上次展开状态，收起不会清空内容，已解锁财务同时重新锁定。时间管理收起时，已展开的飞书日程填满剩余窗口高度，可独立上下滚动；重新展开时间管理后，日程恢复紧凑高度。标题右侧保留保存状态。

## 记录编辑与显示方式

待办、项目与商务记录可在“一览”和各自分页单击名称或进度备注打开编辑，保存后更新原记录。其他本机已写过的开发、历史复盘、备忘和已解锁财务可双击打开编辑。单击完成框仍用于勾选；键盘聚焦记录后按 Enter / F2 也可编辑。今日复盘输入框可直接继续填写。飞书日程保持只读，在飞书中维护。

项目、开发支持“短列表 / 长列表”：短列表显示紧凑摘要，长列表展开完整说明。待办页和商务页也始终以单行展示名称和右侧小字备注，长短列表只调整行距。“一览”始终以单行展示每条记录：左侧名称，右侧小字备注；过长备注以省略号显示，编辑窗口保留完整内容与换行。使用期间可以切换；每次重新打开应用，默认进入“一览 · 长列表”。

“一览”按待办 → 项目 → 商务 → 开发 → 复盘 → 备忘的顺序展示，不加栏目标题、不复制原记录；每类内部按日期倒序，左边保留日期小标。工作项显示名称与右侧小字备注，复盘和备忘显示类型与正文摘要；点击可继续编辑原记录。右上角也可选择六种类型新增。财务保留独立入口。

## 累计时间流

每个分页按记录日期从新到旧排列，左边显示月/日和年份（当天显示“今天”）。同日较新记录优先显示；上下滚动可查看历史。新增记录默认今天，项目、商务、开发、财务可在表单中修改日期。旧项目优先沿用已有日期或时间戳，无法确定时标记“未标日期”。

| 分页 | 使用规则 |
| --- | --- |
| 待办 | 所有待办累计保留，未完成一直显示。勾选后在原日期下保留完成状态，取消勾选可恢复。 |
| 项目 | 填写名称、日期和进度备注；一览与项目列表直接展示备注，长列表保留完整换行，短列表显示紧凑摘要。完成仍用左侧勾选，旧的下一步行动与完成状态保留；支持归档/恢复。 |
| 商务 | 记录客户、事项、推进状态、日期与进度备注。单击名称或备注继续编辑；列表保持名称和右侧小字备注同一行，编辑窗口保留完整备注与换行。支持完成、归档/恢复。 |
| 开发 | 记录项目、事项、日期、时间段、状态与开发目标。所有日期累计保留；支持完成、编辑、归档/恢复。 |
| 复盘 | 今日输入框自动保存，历史复盘按日期累计在同一列表中。双击历史可编辑，“补写”可选过去日期，“搜索”查找档案。换日生成当天输入框，旧内容继续保留。 |
| 财务 | 记录收入/支出、金额、日期、往来方、财务阶段和备注。金额按人民币“分”保存，最多两位小数；支持双击编辑、归档/恢复。新增默认收入，阶段可选择待接洽、待交付、待结算、已结算（总营收）；支出保留待付款/已结清。仅为本机账目记录，不进行转账或付款。 |
| 备忘 | 最后一个分页，记录灵感、资料和临时想法。点击“新增”，选择日期并填写内容，输入后自动保存，回车可换行，点击“完成”关闭编辑；双击旧备忘继续修改。按日期累计，最新在上，支持上下滚动、归档/恢复，并包含在导出中；不随月历选日或换日清空。 |

解锁后，财务标题右侧显示“待接洽 / 待交付 / 待结算 / 总营收”四项金额汇总（元），分别累计全部未归档收入对应阶段的金额；总营收只累计已结算收入，支出不计入。修改金额、切换阶段或归档后立即重算；切换月份不改变汇总范围。新增和双击编辑账目时使用同一组阶段选项。旧版“接洽 / 待收 / 实收”分别显示为“待接洽 / 待结算 / 已结算”，保留原状态值和金额，不自动改变账目的实际阶段；可双击自行调整。

标签支持点击和方向键、Home、End。每次启动默认显示“一览 · 长列表”，按顺序汇总待办、项目、商务、开发、复盘和备忘。每个列表独立滚动；已完成事项与历史内容不会因为切换月历日期消失。归档记录通过各分页的“归档”入口查看并恢复。

月历日期格仍显示当天飞书/本机安排摘要和复盘标记。“飞书日程”可展开、收起，记住展开状态；展开后汇总已同步月份中从今天开始的安排，日期由近到远，同日按时间排列，左侧显示日期，可上下滚动。今天以前结束的日程不进入时间线，跨天且今天仍在进行的安排归入今天，原始起止时间不变。点选月历日期不会改变时间线起点；翻月同步后，新月份会加入时间线。跨月安排只显示一次，点击日程可查看详情，日历筛选仍然生效。

## 飞书 CLI 接入

飞书同步需要自行安装官方 `@larksuite/cli`。应用自动寻找 `~/.npm-global/bin/lark-cli`、`~/.local/bin/lark-cli`、Homebrew 与 PATH 中的 CLI，复用官方 CLI 的配置和凭据。界面本身不需要 Node；CLI 由本机 Node 运行。

1. 未安装时按[官方说明](https://github.com/larksuite/cli/blob/main/README.zh.md)执行 `npx @larksuite/cli@latest install`，完成本机应用配置。已有配置直接复用。
2. 在「设置 → 连接飞书 CLI」打开本人授权页面，仅申请 `calendar:calendar:readonly offline_access`。
3. 用户在飞书确认后，应用完成登录并读取日历，每分钟自动刷新，也可手动同步。
4. 在终端完成 CLI 登录后，启动应用会自动识别；未连接时，运行中的应用也会每分钟重新检测，或点击连接立即检查。

应用仅调用 `calendar calendars list` 与 `calendar events instance_view`，明确指定 `--as user`；不会把机器人空日历当作个人日程。Token 由官方 CLI 管理，不复制到网页或日志。断开仅停止本应用使用 CLI 并清空日历缓存，不注销其他工具共用的 CLI 登录。

### 可选手动 API 模式

在设置中展开「使用自建应用手动连接」：

1. 在[飞书开放平台](https://open.feishu.cn/app)创建企业自建应用，开通用户身份的 `calendar:calendar:readonly` 与 `offline_access`。
2. 添加重定向 URL：`http://127.0.0.1:41863/callback`。
3. 发布应用，将本人加入可用范围，按企业要求完成审批。
4. 把 App ID、App Secret 直接填进本机应用，然后授权。请不要把 Secret 发到聊天。

此模式的凭据存入 macOS 钥匙串。OAuth 使用 state、S256 PKCE 与飞书 v3 Token 端点，并保存轮换后的 Refresh Token。包内不预置凭据。

### 同步边界

- 应用运行时刷新当前月、下个月和查看中的月份；后续安排会进入飞书日程时间线，列表右侧保留滚动条，可用滚轮、触控板或拖动滚动条上下查看。
- 全部读取成功后替换该月快照，使新增、修改、删除和取消跟随飞书；失败保留上次数据并显示错误。
- 日历列表完整分页；日程实例视图展开重复日程与例外，超过接口实例上限时递归拆分范围、按实例 ID 去重。
- 支持有 reader / writer / owner 权限的主日历、共享日历；不展示外接 Google、Exchange、资源或仅忙闲可见日历。
- 保留标题、时间、全天/多日、地点、备注、原始颜色数据和日程/会议链接，按本机时区显示；界面中飞书安排统一蓝色，本机添加的安排统一红色。
- 本机待办、项目、商务、开发与复盘不写回飞书；商务和开发是手动记录，不自动给飞书日程分类。
- 电脑睡眠、应用退出时不读取新变更；这不是飞书界面的即时镜像。

## 财务密码

首次进入财务页，点击“设置财务密码”，在本机安全输入框中输入两次密码（至少 6 位）；不要把密码发到聊天。已有账目会保留。设置完成后，后续打开应用需输入密码才能查看账目、金额汇总和数量。可在“设置 → 财务密码”验证旧密码后修改新密码。

切换离开财务分页、点击“锁定”、收起窗口、电脑休眠/锁屏，以及 5 分钟无操作后会重新锁定。锁定会清空网页中的账目与输入框，并阻止原生端读取或修改财务；“一览”不包含财务。锁定时导出只包含其他记录，文件名弹窗会说明范围。

升级时先将旧财务加密并执行解密回读一致性校验，成功后才从普通 `state.json` 移除明文。首次设密前，迁移密钥暂存在本机钥匙串；界面仍保持锁定。设密后使用 PBKDF2-HMAC-SHA256（310,000 次、独立随机盐）派生 AES-256-GCM 密钥，并移除临时钥匙串密钥。密码只经过原生安全输入框，不写入网页、记录文件或日志。密码遗忘后无法解锁这份加密保险箱，请妥善保管。

该密码保护 Mac 应用和新版财务文件。旧版导出的 JSON、历史截图与既有备份不会随新密码自动加密。浏览器仅预览工作列表，财务设密与解锁需要 Mac 应用。

## 自动保存与复盘归档

输入后 220ms 自动保存，失去焦点、切换日期、退出时也会保存。为兼容旧版，目录沿用 `~/Library/Application Support/在场/`，应用标识保持 `local.zaichang.desktop`。

- `state.json`：非财务记录及设置，字段为 `tasks`、`projects`、`business`、`development`、`thoughts`、`memos`；不再保存明文财务。
- `finance-vault.json`：加密财务保险箱。
- `calendar-cache.json`：飞书日历快照。
- `reflections/YYYY-MM-DD.md`：每一天复盘的独立 Markdown。新版启动时补齐旧复盘归档；编辑或清空同一天会更新相应文件。
- 目录权限 0700，文件权限 0600。手动 API 模式的凭据保存在钥匙串服务 `local.zaichang.desktop`。

「每日复盘 → 历史」可搜索日期、正文并回看；归档文件夹可在历史弹窗中打开。「导出记录」导出本机记录（含归档），不含凭据或飞书日历数据。财务锁定时导出仅包含其他记录；解锁后导出才包含财务，并标记 `financeIncluded`。独立归档仍在同一台 Mac，跨设备备份可把导出文件存到自己选择的位置。

## 提醒

设置可开启每日复盘系统通知并选择时间。飞书日程提醒提前 10 分钟，针对已同步的未来非全天日程，每次最多安排 50 条。系统通知、专注模式、休眠会影响送达。开发日程的本机时间段用于记录，不单独创建系统通知。首次开启提醒才请求系统通知权限。
