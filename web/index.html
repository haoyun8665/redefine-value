连接飞书，只需配置一次

  1. 打开飞书开放平台，创建企业自建应用。
  2. 在“权限管理”开通用户身份权限：calendar:calendar:readonly 和 offline_access。
  3. 在“安全设置 → 重定向 URL”加入：http://127.0.0.1:41863/callback。
  4. 发布应用版本，将你自己加入可用范围；权限审批按企业设置完成。
  5. 在本机应用设置中填入 App ID、App Secret，点击“连接飞书”，在浏览器确认授权。

凭据保存在 macOS 钥匙串，思考和事项保存在本机。飞书授权完成后会替换演示日程。暂不支持飞书中外接的 Google / Exchange 日历，以及仅可看忙闲的日历。

同步保留日历原始时间，界面按这台 Mac 的时区显示；飞书安排统一蓝色，本机添加的安排统一红色。
